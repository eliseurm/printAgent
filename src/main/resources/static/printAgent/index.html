Documentação e manual da API

Guia rápido da API REST v1 executada neste computador.

Endereço base

http://localhost:18181/api/v1

Como enviar uma impressão

  1. Consulte GET /impressoras e copie exatamente o nome da impressora.
  2. Monte o JSON com impressora, trabalho e documento.
  3. Envie-o para POST /trabalhos com Content-Type: application/json.
  4. Use o identificador retornado em GET /trabalhos/{id}.

Tipos de conteúdo

TipoCodificaçãoObservação
